# Arch thoughts
* Anomaly detection at scale with autonomous response across realms of authority and response convergence across entities is the only way to stay ahead of autonomous adversarial AI. eBPF and other integrated eBPF from ring 0 up will improve anomaly detection capabilities and allow orchestrating AI to evaluate needs in real time.
* Using user mandate and compute-at-funding, as well as compute negotiations across entities during transactions will significantly narrow the attack surface and drastically complicate analysis during attacks, as 'apps' - function recipes blended JIT - will be different in every environment and temporally dynamic. A running 'app' can change code in the middle of a runtime sequence. 

# Flaws
* Ledger compute itself will be a heavy draw on endpoints; full ledger systems may be too much. A micro implementation may be ideal for maintaining record, integrating mandates, and proving process lineages for funding.
